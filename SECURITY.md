# Security Policy

## Reporting a vulnerability in phpusing

Please report privately through GitHub Security Advisories ("Report a vulnerability" on the repository). Do not open a public issue.

Include the affected version, steps to reproduce and impact. We aim to reply within 7 days.

In scope: data leaving the browser, secret contents appearing in results or messages, request limits being bypassed, signature verification bypass for advisory data, XSS from scanned content.

## Reporting a wrong result

False positives and missed findings are not security issues. Open a normal issue with the check ID (for example `EX-01`) and a description. Never paste real secrets, `.env` contents or private URLs.

## Supported versions

Only the latest release on the Chrome Web Store.
