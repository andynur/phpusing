# 07 — Internationalization (EN / ID)

## Rules

- `src/shared/i18n/en.json` is the source of truth. `id.json` has exactly the same keys. A test fails on missing, extra or empty keys, and on mismatched `{placeholders}`.
- Every visible string, `aria-label`, `title` and copied developer message goes through `t(key, vars?)`.
- Manifest strings (name, description, action title) use Chrome `_locales/en` and `_locales/id`. These follow the browser language, not the in-app toggle; that is expected.
- The in-app toggle is stored in `settings.lang` and applies instantly without reload.
- Default: `navigator.language` starting with `id` → `id`, else `en`.

## Key naming

`<area>.<item>[.<part>]`, lower camel case parts.

```
popup.checkThisSite
consent.label
verdict.major.title
verdict.major.body
check.EX-01.title
check.EX-01.impact
check.EX-01.fix
severity.critical
confidence.likely
message.header
```

## Developer message language

The copied message has its own EN/ID selector (default: current UI language) because the owner's developer may prefer English.

## Tone in ID

Use "Anda", not "kamu". Short sentences. Avoid English loanwords when a common Indonesian word exists, except glossary terms. The *pusing* wordplay appears only in verdict titles and empty states (see `DESIGN.md` §5).
